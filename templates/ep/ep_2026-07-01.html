ホストOSでの性能測定

グループ：Gr03学籍番号・氏名：123D024 大槻 雅宜学籍番号・氏名：123D075 添野 真之介

1. 実験の目的

KVMとDockerの性能を定量的に比較・分析し、それぞれの特性と適用条件を明らかにします。CPU・メモリ・ストレージ・ネットワーク性能の差、CPUアフィニティやCPU割り当ての影響を調べ、用途に応じた選定指針を検討します。

2. 実験環境

2-1. ホストOS

  • OS：Ubuntu Server 26.04 LTS（Resolute Raccoon）
  • カーネル：GNU/Linux 7.00-27-generic
  • アーキテクチャ：x86_64（amd64）

Ubuntu 26.04.1公開後には同一手順で再実験し、結果の再現性を確認します。

2-2. 比較対象

環境構成概要
A：ホストOSホストOS上で直接ベンチマークを実行する比較基準
B：VM単体KVM上の仮想マシン内で実行
C：Docker単体ホストOS上のDockerコンテナ内で実行
D：VM上DockerKVMの仮想マシン内でDockerコンテナを実行

3. 測定ツールと測定項目

測定項目ツール主な指標実行例
CPU性能SysBench演算速度・スループットsysbench cpu --threads=4 --time=30 run
メモリ性能SysBench帯域幅・レイテンシsysbench memory --memory-total-size=10G run
ストレージI/OfioIOPS・スループット・レイテンシfio --rw=randread --bs=4k --direct=1 ...
ネットワークiperf3TCP/UDPスループット・ジッタiperf3 -c <IP> -t 10 -P 4 --json

4. ホストOSでのベンチマーク手順

  1. ホストOSでベンチマークを実行する自動化スクリプトを作成する。
  2. 完成したスクリプトを10回実行し、結果を保存する。
  3. 測定データに明らかな異常がないか確認する。
  4. 問題がなければグラフ化し、結果を整理する。

5. 分析の方針

各環境で同じツールと条件を使い、CPU・メモリ・ストレージ・ネットワークの測定結果を比較します。測定のばらつきや環境構成を記録し、CPUアフィニティやCPU割り当て方法による変化も分析します。
