KVMとDockerの性能比較に向けたOSインストール

グループ：Gr03学籍番号・氏名：123D024 大槻 雅宜学籍番号・氏名：123D075 添野 真之介

1. 実験の目的

本実験では、サーバー仮想化技術（KVM）とコンテナ技術（Docker）の性能を定量的に比較・分析し、それぞれの特性と適用条件を明らかにします。また、用途に応じた効率的な運用方法を検討します。

具体的には、各仮想化環境（VM単体・Docker単体・VM上Docker）のCPU、メモリ、ストレージ、ネットワーク性能の差異、CPUアフィニティやCPU割り当て方法の影響を調べ、用途ごとの選定指針を提示します。

2. 実験環境

2-1. ホストOS

  • OS：Ubuntu Server 26.04 LTS（Resolute Raccoon）
  • カーネル：GNU/Linux 7.00-27-generic
  • アーキテクチャ：x86_64（amd64）

Ubuntu 26.04.1公開後には同一手順で再実験し、結果の再現性を確認します。

2-2. 比較対象の4環境

環境構成概要
AホストOS（Ubuntu）ホストOS上で直接ベンチマークを実行する比較基準
BVM単体KVM/QEMUで構築したUbuntu VM内で実行
CDocker単体ホストOS上のUbuntuコンテナ内で実行
DVM上DockerKVMのVM内に構築したDockerコンテナ内で実行

3. 測定ツールと測定項目

測定項目ツール主な指標実行例

メモリ性能SysBench帯域幅・レイテンシsysbench memory --memory-total-size=10G run

4. 環境準備

4-1. OSインストーラーの準備

Ubuntu公式サイトからUbuntu Server 26.04 LTSのISOファイルをダウンロードします。USBインストールメディアの作成には、Rufus公式サイトからWindows x64版（rufus-4.14.exe）をダウンロードして使用します。

Rufusは、起動可能なUSBインストールメディアを作成するためのソフトウェアです。

4-2. OSインストール

  1. 作成したUSBインストールメディアをデスクトップPCに接続して起動する。
  2. BIOSを開き、起動順位を変更してUSBを1番に設定する。
  3. 設定を保存してBIOSを終了し、Ubuntuのインストーラーを起動する。
  4. 画面の指示に従ってUbuntuのインストールを完了する。

5. OS初期設定

インストール後、システムを最新の状態に更新します。

sudo apt update
sudo apt upgrade

更新が完了したら再起動し、タイムゾーンを日本標準時に設定します。

sudo timedatectl set-timezone Asia/Tokyo

以上でOSの初期設定を完了とします。
