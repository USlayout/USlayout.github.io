fio・sysbench・iperf3の測定結果を平均値・中央値で整理

グループ：Gr03 学籍番号・氏名：123D024 大槻 雅宜 学籍番号・氏名：123D075 添野 真之介

研究テーマ

サーバー仮想化技術とコンテナ技術の性能比較および最適化に関する研究

進捗状況

本日は、ホスト環境で行った fio、sysbench、iperf3 の各測定結果を 10 回分まとめ、平均値と中央値を整理した。これにより、測定ごとのばらつきと代表値の傾向を把握しやすくなった。pコア4コアにして測定しました。また、ホスト環境ベンチマーク後VMを構築しsysbench,fioを実行しました。結果は計算等していません。

  • fio では rand_read / rand_write の IOPS と処理性能をまとめ、平均値・中央値を確認した。
  • sysbench では CPU と memory read/write の処理数と帯域幅を整理し、安定性の把握を行った。
  • iperf3 では TCP / UDP の転送速度を平均値・中央値の観点から比較した。
10回測定の代表値一覧
測定項目 平均値 中央値 単位
fio rand_read 627,332.20 627,356.97 IOPS
fio rand_write 714,728.81 715,387.80 IOPS
sysbench CPU 6,060.19 6,060.40 events/sec
sysbench memory read 40,453.85 40,602.96 MiB/sec
iperf3 TCP 927.749 936.851 Mbps
iperf3 UDP 955.948 955.953 Mbps

今回の整理では、平均値と中央値を並べて確認することで、個々の測定結果における外れ値の影響を見抜きやすくした。特に iperf3 UDP は平均値と中央値がほぼ一致しており、通信性能が比較的安定していると判断できる。

今後の計画

  • fio、sysbench、iperf3 の結果を同じ形式で比較できるように、集計表とグラフを整理する。
  • 各実験条件ごとの差分が分かるように、CPU、メモリ、ネットワークの比較軸を揃える。
  • 最終的な研究報告書へ反映するため、測定条件と代表値の説明文を追記する。
