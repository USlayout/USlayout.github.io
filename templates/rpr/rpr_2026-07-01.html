進捗状況

OSのインストールと初期設定

実験計画書に従い、OSのインストールおよび初期設定を実施しました。

まず、パッケージを最新の状態に更新し、不要なパッケージを削除しました。

sudo apt update
sudo apt upgrade
sudo apt autoremove

ネットワーク設定と時刻同期

タイムゾーンを変更した後もシステム時刻が正しく設定されず、timedatectl statusで確認すると、System clock synchronizedがnoになっていました。

原因を調査するため、ip aでネットワーク設定を確認したところ、ネットワークに接続されていないことが判明しました。そこで、00-installer-config.yamlを編集し、dhcp4: trueを設定してDHCPによるIPアドレスの自動取得を有効にしました。

ネットワーク接続後も時刻同期が改善されなかったため、Wi-Fi接続の設定を追加しました。さらに、時刻同期サービスが導入されていないことが原因と考え、以下のコマンドを実行しました。

sudo apt install system-timesyncd -y
sudo systemctl enable --now system-timesyncd

timedatectl statusで確認した結果、システム時刻が正常に同期されることを確認しました。

実験用ソフトウェアの導入

初期設定の完了後、実験で使用する以下のソフトウェアをインストールし、正常に動作することを確認しました。

  • OpenSSH Server
  • sysbench
  • fio
  • iperf3

リモート接続およびネットワーク性能測定を容易にするため、SSHとiperf3のサービス自動起動を有効化しました。
