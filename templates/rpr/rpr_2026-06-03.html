KVM・Docker・ベンチマーク環境の構築状況

グループ：Gr03学籍番号・氏名：123D024 大槻 雅宜 学籍番号・氏名：123D075 添野真之介

研究テーマ

サーバー仮想化技術とコンテナ技術の性能比較および最適化に関する研究

進捗状況

今回は、KVM、Docker、SysBench、fio、iperf3 を用いた比較環境の構築手順を整理し、今後の実験に必要な前提条件を確認した。

1. KVM の構築

KVM を利用するため、CPU の仮想化支援機能と必要なパッケージを確認した。仮想化対応の確認は以下で行う。

BASH

仮想化対応確認

grep -E 'vmx|svm' /proc/cpuinfo | head -5
lscpu | grep Virtualization

vmx（Intel）または svm（AMD）が表示されれば仮想化対応と判断できる。対応していない場合は BIOS/UEFI の Virtualization Technology を有効にする。

導入手順は次の通りである。

BASH

KVM パッケージ導入

sudo apt update && sudo apt upgrade -y
sudo apt install -y qemu-kvm libvirt-daemon-system libvirt-clients \
  bridge-utils virt-manager virtinst
sudo systemctl enable --now libvirtd
sudo usermod -aG libvirt,kvm $(whoami)
newgrp libvirt

主なパッケージの役割は以下の通り。

パッケージ役割
qemu-kvmQEMU エミュレータ（KVM のバックエンド）
libvirt-daemon-systemlibvirt デーモン（VM 管理 API）
libvirt-clientsvirsh コマンドラインツール
bridge-utilsブリッジネットワーク設定
virt-managerGUI ベースの VM 管理
virtinstvirt-install による CLI での VM 作成

動作確認では次のコマンドを使い、VM の登録状況とネットワーク状態を確認する。

BASH

動作確認

virsh list --all
virsh net-list --all
sudo virsh net-start default && sudo virsh net-autostart default

VM 作成の例は以下の通りである。

BASH

Ubuntu VM 作成例

virt-install \
  --name ubuntu-vm \
  --ram 2048 \
  --vcpus 2 \
  --disk path=/var/lib/libvirt/images/ubuntu-vm.qcow2,size=20 \
  --os-variant ubuntu24.04 \
  --cdrom /path/to/ubuntu-24.04.iso \
  --network network=default \
  --graphics none \
  --console pty,target_type=serial

2. Docker の構築

Docker Engine の導入では、競合パッケージの除去と公式リポジトリの追加を行った。公式ドキュメントの案内に従って構築を進める。

BASH

Docker インストール

for pkg in docker.io docker-doc docker-compose docker-compose-v2 \
           podman-docker containerd runc; do
  sudo apt-get remove $pkg
done

sudo apt-get update
sudo apt-get install -y ca-certificates curl
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg \
  -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc

echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] \
  https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo "$VERSION_CODENAME") stable" \
  | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

sudo apt-get update
sudo apt-get install -y docker-ce docker-ce-cli containerd.io \
  docker-buildx-plugin docker-compose-plugin

sudo usermod -aG docker $(whoami)
newgrp docker
sudo systemctl enable --now docker
docker run hello-world

3. ベンチマークツールのインストール

CPU・メモリ・ストレージ・ネットワーク性能の比較に向けて、SysBench、fio、iperf3 を導入した。パッケージマネージャからまとめてインストールできる。

BASH

ベンチマーク導入

sudo apt update
sudo apt install -y sysbench fio iperf3
ツール主な用途
SysBenchCPU・メモリ性能の測定
fioストレージ I/O の測定
iperf3ネットワークスループットの測定

代表的な実行例を以下に示す。

BASH

実行例

# CPU（単一スレッド）
sysbench cpu --cpu-max-prime=20000 --threads=1 --time=30 run

# CPU（マルチスレッド）
sysbench cpu --cpu-max-prime=20000 --threads=$(nproc) --time=60 run

# メモリ
sysbench memory --memory-total-size=10G --threads=4 run

# fio（ランダム読み込み）
fio --name=rand-read --ioengine=libaio --direct=1 \
  --rw=randread --bs=4k --iodepth=16 \
  --size=1G --runtime=30 --time_based \
  --filename=/tmp/fio-test.dat --output-format=json

# iperf3（TCP）
iperf3 -c <サーバーIPアドレス> -t 10 -P 4 --json

# iperf3（UDP）
iperf3 -c <サーバーIPアドレス> -u -b 1G -t 10 --json

4. VM 上 Docker の構築

  1. KVM で Ubuntu VM を起動し、SSH でログインする。
  2. VM 内で Docker の構築手順をそのまま実施する。
  3. SysBench、fio、iperf3 を VM 内でも導入する。
  4. ホスト直接実行と比較するため、Docker コンテナ内でベンチマークを実行する。

ネスト仮想化を利用する場合は、Intel 系の環境では sudo modprobe kvm_intel nested=1 で有効化できる。
